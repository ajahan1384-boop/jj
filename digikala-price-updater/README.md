# به‌روزرسانی قیمت اکسل دیجی‌کالا

این ابزار یک برنامه‌ی دسکتاپ ساده (با رابط گرافیکی) است که به‌صورت کاملاً
لوکال روی کامپیوتر خودتان اجرا می‌شود — هیچ فایلی به سروری ارسال نمی‌شود.

## کاری که انجام می‌دهد

برای هر فایل اکسل انتخاب‌شده:

1. شیت **«داده ها»** را باز می‌کند.
2. مقدار هر سلول **ستون J («(ریال)قیمت فروش»)** را در **ضریب** واردشده
   ضرب می‌کند.
3. نتیجه را تا **۴ رقم اعشار به سمت بالا (Round Up / Ceiling)** گرد می‌کند.
4. بقیه‌ی فایل — شیت «راهنما»، استایل‌ها، ستون‌های دیگر، ترتیب شیت‌ها —
   دقیقاً دست‌نخورده باقی می‌ماند، چون فایل به‌جای بازسازی از صفر، مستقیماً
   ویرایش و با نامی جدید ذخیره می‌شود (فایل ورودی هرگز تغییر/بازنویسی
   نمی‌شود).

خروجی هر فایل با نام `<نام‌اصلی>_x<ضریب>.xlsx` در پوشه‌ی خروجی (پیش‌فرض:
پوشه‌ی `output` کنار فایل ورودی، یا پوشه‌ای که خودتان انتخاب می‌کنید)
ذخیره می‌شود.

## پیش‌نیاز

- Python 3.9 یا بالاتر (نسخه‌های رسمی از [python.org](https://python.org)
  به‌صورت پیش‌فرض شامل رابط گرافیکی tkinter هستند).

## نصب و اجرا

```bash
cd digikala-price-updater
pip install -r requirements.txt
python price_updater.py
```

روی ویندوز معمولاً کافی است دستور را با `python` یا `py` اجرا کنید.

## استفاده

1. **ضریب قیمت** را وارد کنید (مثلاً `1.15` برای ۱۵٪ افزایش).
2. روی **«انتخاب فایل‌های اکسل...»** بزنید و تا ۵۰ فایل (یا بیشتر) را
   هم‌زمان انتخاب کنید.
3. در صورت نیاز، **پوشه خروجی** و **تعداد پردازش هم‌زمان** را تنظیم کنید
   (پیش‌فرض بر اساس تعداد هسته‌های سیستم شما و با کنار گذاشتن یک هسته
   آزاد انتخاب می‌شود تا سیستم شما تحت فشار قرار نگیرد).
4. روی **«شروع پردازش»** بزنید. پیشرفت و نتیجه‌ی هر فایل (موفق/ناموفق و
   دلیل) در بخش «گزارش» نمایش داده می‌شود.

## نکات

- فایل‌های ورودی باید فرمت **xlsx** داشته باشند.
- اگر فایلی خراب باشد، فرمت نامعتبر داشته باشد، در برنامه‌ی دیگری باز
  باشد یا شیت/ستون موردنظر را نداشته باشد، همان یک فایل با پیغام خطا در
  گزارش علامت می‌خورد و **بقیه‌ی فایل‌ها بدون وقفه پردازش می‌شوند** —
  برنامه هرگز به‌خاطر خطای یک فایل متوقف یا بسته نمی‌شود.
- پردازش با تعداد پردازه محدود (کمتر از تعداد هسته‌های واقعی) انجام
  می‌شود تا از سخت‌افزار سیستم استفاده‌ی بهینه شود بدون این‌که کامپیوتر
  را کند یا داغ کند؛ برای فایل‌های حجیم (مثلاً ۳۰ هزار ردیفی) طول کشیدن
  پردازش چند ثانیه تا چند دقیقه طبیعی است.
