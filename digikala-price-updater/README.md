# به‌روزرسانی قیمت اکسل دیجی‌کالا

ابزاری که به‌صورت کاملاً لوکال روی کامپیوتر خودتان اجرا می‌شود — هیچ فایلی
به سرور یا اینترنت ارسال نمی‌شود.

## کاری که انجام می‌دهد

برای هر فایل اکسل انتخاب‌شده:

1. شیت **«داده ها»** را باز می‌کند.
2. مقدار هر سلول **ستون J («(ریال)قیمت فروش»)** را در **ضریب** واردشده
   ضرب می‌کند.
3. نتیجه را تا **۴ رقم اعشار به سمت بالا (Round Up / Ceiling)** گرد می‌کند.
4. بقیه‌ی فایل — شیت «راهنما»، استایل‌ها، ستون‌های دیگر، ترتیب شیت‌ها —
   دقیقاً دست‌نخورده باقی می‌ماند، چون فایل به‌جای بازسازی از صفر، مستقیماً
   ویرایش و با نامی جدید ذخیره می‌شود (فایل ورودی هرگز تغییر/بازنویسی
   نمی‌شود).

## دو روش اجرا

### ۱) رابط وب (پیشنهادی، ساده‌تر)

یک سرور کوچک پس‌زمینه روی خود سیستم شما بالا می‌آید و یک صفحه HTML به‌عنوان
رابط کاربری باز می‌شود؛ همان‌جا فایل‌ها را (با درگ‌اندراپ یا کلیک) انتخاب و
ضریب را وارد می‌کنید.

```bash
cd digikala-price-updater
pip install -r requirements.txt
python web_app.py
```

مرورگر به‌صورت خودکار روی آدرس `http://127.0.0.1:8765` باز می‌شود (اگر باز
نشد، خودتان این آدرس را در مرورگر وارد کنید). برای توقف سرور، همان پنجره
ترمینال را ببندید یا `Ctrl+C` بزنید.

در صفحه:

1. **ضریب قیمت** را وارد کنید (مثلاً `1.15`).
2. فایل‌ها را در کادر بکشید یا با کلیک انتخاب کنید (تا ۵۰ فایل یا بیشتر).
3. روی **«شروع پردازش»** بزنید و پیشرفت/نتیجه هر فایل را ببینید.
4. هر فایل را جدا یا همه را یک‌جا (**دانلود همه ZIP**) دانلود کنید.

### ۲) رابط دسکتاپ (tkinter)

یک پنجره‌ی برنامه‌ی جداگانه، بدون نیاز به مرورگر:

```bash
cd digikala-price-updater
pip install -r requirements.txt
python price_updater.py
```

## پیش‌نیاز

- Python 3.9 یا بالاتر.
- برای رابط دسکتاپ، پایتون باید شامل tkinter باشد (نسخه‌های رسمی
  [python.org](https://python.org) به‌صورت پیش‌فرض دارند).

## نکات

- فایل‌های ورودی باید فرمت **xlsx** داشته باشند.
- اگر فایلی خراب باشد، فرمت نامعتبر داشته باشد، در برنامه‌ی دیگری باز
  باشد یا شیت/ستون موردنظر را نداشته باشد، همان یک فایل با پیغام خطا
  علامت می‌خورد و **بقیه‌ی فایل‌ها بدون وقفه پردازش می‌شوند** — برنامه
  هرگز به‌خاطر خطای یک فایل متوقف یا کرش نمی‌شود.
- پردازش با تعداد پردازه محدود (کمتر از تعداد هسته‌های واقعی سیستم) انجام
  می‌شود تا از سخت‌افزار استفاده‌ی بهینه شود بدون این‌که کامپیوتر را کند یا
  داغ کند؛ برای فایل‌های حجیم (مثلاً ۳۰ هزار ردیفی) طول کشیدن پردازش چند
  ثانیه تا چند دقیقه طبیعی است.
- در رابط وب، فایل‌های آپلودشده و خروجی‌ها موقتاً داخل پوشه‌ی
  `digikala-price-updater/_jobs/` ذخیره می‌شوند (این پوشه در گیت ردیابی
  نمی‌شود) و هر ۲۴ ساعت پردازش‌های قدیمی خودبه‌خود پاک می‌شوند.

## ساختار فایل‌ها

- `core.py` — منطق مشترک پردازش اکسل (بدون وابستگی به رابط کاربری).
- `web_app.py` — سرور وب محلی (Flask) + رابط HTML.
- `price_updater.py` — رابط دسکتاپ (tkinter)، جایگزین رابط وب.
- `static/index.html` — صفحه‌ی رابط کاربری وب.
